# Dupont Plomberie - Site Web

Site web professionnel pour Dupont Plomberie, artisan plombier certifié RGE en Île-de-France.

## À propos

Site vitrine moderne présentant les services de plomberie, dépannage urgent, et rénovation.

## Installation

1. Cloner le repository
2. Naviguer dans le répertoire du projet
3. Installer les dépendances: `npm install`
4. Lancer l'application: `npm run dev`

## Technologies

- React + Vite
- TailwindCSS
- Framer Motion
- React Router

## Structure du projet

- `/src/components` - Composants réutilisables
- `/src/pages` - Pages de l'application
- `/src/lib` - Utilitaires et configuration

## Développement

Pour lancer le serveur de développement:

```bash
npm run dev
```

Pour créer une version de production:

```bash
npm run build
```
